1. Design

The firmware runs FreeRTOS on both CPU cores. The work is split into six pinned tasks. Each task runs on a fixed period with vTaskDelayUntil and checks in with the task watchdog on every cycle. All tasks share one state struct protected by a mutex. Serial output goes through a print mutex with a 50 ms timeout, so no task ever blocks waiting. Only the indicator task drives the RGB LED, following the Device Signals priority (sensor error 6 beats Safe 11). The main task (the Arduino loop) reads commands without blocking and prints [STATUS] every 1 s.

  • One line per tap: each 200 ms poll sends WUPA (which also wakes a halted card), reads the card and halts it. A new [CARD] line is printed only after 400 ms of absence, so a card held on the reader gives exactly one line.
  • Sensor errors: DHT11 fails 2 reads in a row → SENSOR ERROR: DHT11 within 10 s (limit 12 s). The RC522 version register stops matching the value read at boot (0x82, clone chip) for 1 s → SENSOR ERROR: RFID (limit 3 s). The light turns magenta, the other tasks keep running, and both errors clear by themselves.
  • Watchdog: 8 s with panic; reset reason → POWER_ON / SOFTWARE / WATCHDOG / CRASH / BROWNOUT. Start-up: the flame sensor is read (5 samples) before any task starts: no flame → LOCKED, flame → UNLOCKED.

4. Problems and fixes

ProblemFix
Our RC522 is a clone (version 0x82), so a fixed list of known versions gave a false sensor error.Compare with the version read at boot; 0x00/0xFF (SDA unplugged) → error.
A card held on the reader was read again and again.Halt after each read; count a new tap only after 400 ms of absence → 3 taps + 1 hold = 4 lines.
esp_task_wdt_init() changed in Arduino-ESP32 3.x, so the build failed.Version-guarded set-up; team standard is core 2.0.17 (has the Level 7 face detector).
Practice run showed psram=0k: the IDE option "PSRAM" was disabled.Tools → PSRAM → "OPI PSRAM"; the firmware now prints [ERROR] PSRAM not found at boot.
Native USB drops the Serial Monitor on every reset.Use the USB-UART (CH343) port, COM5, with "USB CDC On Boot" disabled.
