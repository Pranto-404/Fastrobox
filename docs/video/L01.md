# Level 1 video: shot list

**Rules:** ≥ 720p (record 1080p), clear audio, ≤ 10 min, up to 3 **unedited** clips. A team member states the Team ID and level at the start. The Serial Monitor and a running stopwatch must be visible for every timed item. File name: `<TeamID>_L01_video.mp4`.

**Required item ("Video must show"):** the DHT11 data wire and the RC522 SDA wire unplugged for 15 s. Expect `SENSOR ERROR` for RFID within 3 s and for DHT11 within 12 s, magenta light, no freeze, and both clear after reconnecting.
We also film every live check, so the write-up's test table can cite a video time for each one.

## Set-up (before pressing record)
- [ ] Phone on a tripod, **landscape, 1080p 30 fps**, Do-Not-Disturb on, about 10 min of free storage
- [ ] One frame shows **the laptop screen and the board** (the LED must be clearly visible)
- [ ] Laptop screen: Serial Monitor on the left (font enlarged), a **big online stopwatch** on the right, running
- [ ] Serial Monitor: 115200, New Line, **autoscroll on, timestamps on** (clock icon)
- [ ] Wires to unplug are easy to reach: DHT11 DATA (GPIO 1) and RC522 SDA (GPIO 41)
- [ ] Card + key tag, lighter on the table; quiet room

## Clip 1: live checks (~3 min)
| Time | Do | Say | Must be visible |
|---|---|---|---|
| 0:00 | Start the stopwatch | "Team T__, Level 01: Dual-Core Tasks, Health and Watchdog." | Stopwatch running |
| 0:10 | Press **RST** | "Restart." | `[EVENT] BOOT reason=POWER_ON`, `door=LOCKED` |
| 0:20 | Point at the LED, then the screen | "Green 2 Hz heartbeat, a STATUS line every second." | LED blinking; timestamps 1 s apart |
| 0:40 | Tap the card **3 times**, then **hold it 5 s** | "Three taps and one hold: four card lines." | Exactly 4 `[CARD] uid=…` lines |
| 1:05 | Type `help`, `status`, `health`, `tasks`, `ver` | "Tasks run on core 0 and core 1." | Every reply; `tasks` shows both cores |
| 1:50 | Type `hang` | "Main task frozen; watchdog test." | Stopwatch |
| ~2:00 | Wait | "Restarted in N seconds by itself." | `BOOT reason=WATCHDOG` < 10 s, `door=LOCKED` |

## Clip 2: sensor errors (the required item, ~1.5 min)
| Time | Do | Say | Must be visible |
|---|---|---|---|
| 0:00 | Show the stopwatch | "Team T__, Level 01, sensor-error test." | |
| 0:05 | Unplug **both** DHT11 DATA and RC522 SDA | "Unplugging both now at <stopwatch time>." | Hands on the wires, stopwatch |
| ≤ 0:08 | Wait | "RFID error within 3 s." | `[ERROR] SENSOR ERROR: RFID`, magenta LED |
| ≤ 0:17 | Wait | "DHT11 error within 12 s." | `[ERROR] SENSOR ERROR: DHT11` |
| 0:15 | Type `status` | "The device is not frozen." | STATUS lines keep coming; command answered |
| 0:25 | Reconnect both (unplugged ≥ 15 s) | "Reconnecting." | |
| ≤ 0:35 | Wait | "Both errors cleared; green again." | Both `CLEARED` lines, green LED |

## Clip 3: flame at start-up (write-up item, ~40 s)
| Do | Say | Must be visible |
|---|---|---|
| Hold the lighter in front of the flame sensor, press **RST** | "Flame at start-up." | `DOOR UNLOCKED (flame at start-up: yes)`, `door=UNLOCKED` |
| Lighter away, press **RST** | "No flame at start-up." | `door=LOCKED` |
